# AIOS

Un sistema operativo grafico, **unico per computer, tablet e telefoni**, in cui si
fa tutto parlando con un **copilota AI che gira in locale**:

- *«installa un programma per montare video»* → lo cerca, chiede conferma e lo installa
- *«a che ora parte l'ultimo treno per Milano?»* → cerca su internet e cita le fonti
- *«apri la cartella Scaricati»*, *«quanta memoria ho libera?»*, …

Le applicazioni Linux girano nativamente, molte app Windows tramite Wine/Bottles e
le app Android tramite Waydroid. I dispositivi dello stesso utente sono collegati tra
loro (clipboard, file, notifiche, delega del calcolo AI dal telefono al PC).
